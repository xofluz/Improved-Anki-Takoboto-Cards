# Improved Anki cards for `jp.takoboto` notes

This is a set of recognition and recall cards for notes generated through the Takoboto Android app.

The improvements are:
- Serif fonts are used rather than sans-serif
- The size of the japanese word is increased, to make it the main focus of the card.
- Help text such as the reading and sentence meaning are shown in small gray text.
- On the front side, the reading is by default hidden and can be revealed by clicking the word. If the word has a note containing "Usually written using kana alone", the reading is by default shown.
- The URL of the Takoboto link is extracted if used on a platform other than Android. This makes the link functional by opening [takoboto.jp](https://www.takoboto.jp) rather than the app.
